# Deskwell - E-commerce Store

Full Stack Development internship project (Thiranex, 24 Sept 2026 - 23 Oct 2026).

## Features
- Product listing with search, category filter and sorting
- Cart with quantity update and coupon code `THIRANEX10` (10% off)
- Free delivery above Rs 2,999, otherwise Rs 99
- Sign up / sign in (password hashed with SHA-256)
- Checkout with form validation and order confirmation
- Order history for each user
- Light and dark mode, mobile friendly

## Tech
HTML, CSS, JavaScript (data saved in browser localStorage)

## Run
Open `index.html` in any browser. No install needed.
